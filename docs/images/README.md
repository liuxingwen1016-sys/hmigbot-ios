# docs/images — 图片投放说明

本目录存放 README §5（Codex 桌面版使用说明）的三张截图。把图片按下面的**文件名**放进来即可，README 已引用好位置。

| 文件名 | 应展示的内容 | 对应 README 位置 |
|---|---|---|
| `desktop-open-folder.png` | 桌面版里"打开文件夹/选择工作区"的入口界面 | §5.1 |
| `desktop-hooks-untrusted.png` | 设置 → 编码/开发者 → Hooks 面板，6 个 migbot 钩子处于**未信任**状态（Trust 按钮可点） | §5.2 |
| `desktop-hooks-trusted.png` | 同一面板，6 个钩子已点开 Trust（Active / 已启用状态） | §5.2 |

建议：

- PNG 格式，宽度 ≤ 1200px，单张 ≤ 500KB；
- 截图前把工程目录无关的个人信息（账号邮箱等）遮掉；
- 只放应用窗口本体，不必全屏。
